# TutorSkillGraph

[English](README.md) · 中文

**AI 导师能否从学生后来独立解题时给出的理由，看出上一堂课漏教了什么，并改好下一次教学？** 有些课堂例子，用正确原理和用错误猜法都能答对。学生换题以后说出的理由，可能指明老师需要修改哪一项活动。

**[阅读完整研究方案](RESEARCH_BRIEF.zh-CN.md)**，从一节密度课看懂教学 skill 怎样作为节点、一条超边怎样记录教学假设，以及如何与写得完整的普通 skill 公平比较。目前处于研究设计阶段。首个有真实数据支撑的案例拟从公开的列方程辅导记录中选取。

## 为什么一次成功的辅导也可能教给导师错误的经验？

想象两名学生列围栏长度方程时都漏掉了一项。第一名学生先解释了每一项代表什么。老师问了一句「按你的算法，哪几条边已经算进去了？」学生重新数了一遍，自己发现漏了一条边。第二场对话里，老师先点明漏的是哪条边，再问同一句话，学生也改对了。这是用来说明问题的一组假想对照。

两场辅导都可能有帮助，但它们能给老师留下的经验不一样。第一场里，追问之后，那条遗漏的关系是学生自己说出来的。第二场里，关系已经由老师提供了。如果系统每次看到学生改对，就给「追问」记一功，它可能越来越爱追问，却学错了这一招在什么条件下有用。反过来，一概给直接讲解扣分也不合理。有些学生恰恰需要听一次清楚的解释，之后才能自己用出来。

**我们先用数据问，同样一道错题最后都改对了，学生是怎样改对的，能否提示导师回头检查哪条教学经验？** 在原有水平和所遇困难相近的情况下，如果知道关键关系最早是谁提出来的、学生接下来怎样使用它，我们能否更准确地判断他在变式题上能独立做到哪一步？如果可以，导师下一次遇到相似的困难时，就有依据调整教法。

## 核心想法：让导师学会修订一条教法的适用条件

这里的教学 skill 指可以重复采用的一种教法，例如请学生解释方程中某一项的来历。一条超边把**学生已经表达的判断、导师选来检验它的材料、接下来请学生自己做的那一步思考**连在一起。这三项说清了老师怎样设计这一步。学生回应后，再看关键关系实际由谁提出。之后的独立作答，则给了导师保留或修订这套组合的依据。

| 在什么时候 | 系统能依据什么 |
| --- | --- |
| 选择教法前 | 题目要求、学生已经写下的答案或理由，以及导师已经给过的信息。只看到一个算式时，学生为什么这样写可能还看不出来。 |
| 学生回应后 | 回到具体发言，看关键关系是学生首先提出来的、学生把老师讲过的关系用到了题上，还是只复述了一遍。对话说不清楚时，保留这种不确定性。 |
| 学生独立做题后 | 看同一名学生在相关变式题上的作答。这能帮助导师为以后的学生修订经验。第一次选择教法时，导师还不知道这项结果。 |

例如，导师起初只有一条粗略的经验：「学生方程写错了，就请他解释理由。」假如在可比的学生中，已经主动解释过思路的人和只报了答案的人，接受同样追问后的独立表现一直有区别，这条经验就值得拆开。对前者可以请他检验自己的理由，对后者可以先了解他认为每一项代表什么。如果听过直接解释的学生在新题上也能独立运用，就应该保留这种讲解的适用情形。这些是有待检验的修改方向。

## 五套数据，从观察课堂到检验独立作答

**1. PEA 真实课堂视频：发现文字记录容易漏掉的教学线索。** 想象老师刚指了一下图中漏算的那条边，学生随后第一个把它说出口。只看文字，很容易把发现这条边的功劳全记给学生，或者记给老师最后那句追问。PEA 把 100 段数学和信息技术课堂视频里的五个教学阶段与 27 类言语、非言语事件对齐。公开的时间标注能用来寻找提问与手势重叠的片段，比较它们出现在什么环节。获得原视频授权后，还可以核查手势具体指向了什么。这给技能图提出了一个实在的要求：判断「谁最先给出关键线索」时，要考虑学生之前**听到了什么，也看到了什么**。事件类别本身不足以断定某个手势传达了哪条关系，或某个学生是否学会。标注和类别表已公开，原视频由作者控制访问。[PEA 论文](https://doi.org/10.1145/3767308.3838632) · [数据集](https://github.com/mark1001-ljj/dataset_event) · [原视频访问说明](https://github.com/mark1001-ljj/dataset_event/blob/main/docs/VIDEO_ACCESS.md)

**2. MM-TBA：比较教案打算怎么教，老师在课堂上具体怎么说。** 教学设计子集保留了实习教师的原始教案，并把标注过的教学环节对应到课堂时段和讲课转写。这样可以问一个仅凭手势标签很难回答的问题：教案安排学生自己发现某条关系，但在学生开口前，老师的话里是否已经给出了这条关系？构建候选技能时，可以分别记下「计划让学生自己做什么」和「老师实际提供了哪些线索」。现成的文本和标注就能作为起点。动作检测子集公开了视觉特征和六类逐秒动作标注，包括指向和板书；原始课堂视频未公开分发。讲课评价报告由模型生成，评价的是教学过程。学生后来能否独立完成这一步，要把提炼的假设带到后面有独立作答记录的数据中检验。[论文与数据说明](https://www.nature.com/articles/s41597-025-05426-6) · [Figshare 数据入口](https://doi.org/10.6084/m9.figshare.28942487)

**3. Scaffolded Error Correction：看学生是怎样把同一道题改对的。** 这是研究核心问题的起点。400 名成人被分到四种反馈条件，其中 99 人进入苏格拉底式辅导组。公开资料包括逐人结果和辅导日志。所有人都做了五道没有反馈的后测题，其中三道是对应练习的更难变式。研究允许导师在连续回复六次仍未得到正确方程后直接给出方程。这样就可以沿着对话查：关键关系最早由谁提出，学生接下来怎样使用它，以及这种纠错过程是否有助于判断他能否独立完成对应变式。[数据与字段说明](https://github.com/the-oak-lab/scaffolded-error-correction) · [研究流程](https://arxiv.org/pdf/2611.20061)

**4. GenAI Can Harm Learning：换到高中课堂，看这个区别还重不重要。** 作者公开了带时间戳的学生与 GPT 对话、有辅助的练习成绩、无辅助的考试成绩，以及练习题和相关考试题的对应关系。普通 GPT 和带教学引导的 GPT 提供帮助的方式不同，可以借此考察，在成人列方程任务中发现的规律，到了学校数学课堂还能不能区分学生的独立表现。对话表用 `username` 标识学生，成绩表使用 `Student_ID`。要下逐人结论，须先核实两个标识的对应关系，并对齐场次和题目。在这一步之前，公开的组别结果可以用来比较不同辅导条件下练习和考试表现的差异。[数据字典与题目映射](https://github.com/obastani/GenAICanHarmLearning) · [PNAS 论文](https://doi.org/10.1073/pnas.2422633122)

**5. StudentBench：换导师、换学科，看同一条教学经验还能不能用。** 这项 GRE 研究涵盖 2,383 名参与者、2,469 场学习，包含数学推理和语文推理。公开资料有辅导对话、练习尝试，以及各 27 道题的前测和后测作答。可以在 AI 辅导场次里追问：根据列方程对话归纳的规则，换一个导师，甚至换成语文推理，还能不能帮助判断学生后来的表现？比较时要考虑前测和科目，并在同一场次内对应对话和测验。公开的 `student_id` 是场次编号，作者没有发布跨两个科目关联同一人的身份键。整场后测的变化也不足以单独归功于其中一句话。[数据集与编号说明](https://huggingface.co/datasets/handshake-ai-research/studentbench) · [论文](https://arxiv.org/abs/2609.28470)

先用 PEA 找出一种教法在课堂动作序列中的位置，再用 MM-TBA 区分教案的意图和教师实际给出的线索。把由此形成的**教学假设**带入纠错数据，根据学生独立作答的记录把判断规则说清楚，然后保持规则定义不变，换到另外两项研究检查。各套数据分别提供课堂事件、教案与授课转写、对应变式题成绩、独立考试成绩和考虑前测后的 GRE 表现。跨数据集对照的是教学规律，每个学生的记录只在各自研究内部关联。

## 怎么知道这个想法值不值得继续？

最先要弄清的，是多读一层对话究竟带来了什么信息。在相同的前测和题目信息下，先看**只知道学生改对了**能判断多少，再看加入**他得到了多少帮助**后能判断多少，最后才加入**关键关系由谁提出、学生怎样使用**。用形成规则时没见过的学生做比较。如果最后一层确实有用，再让普通条件规则、带状态的有向图和超图使用同样的信息。如果一句清晰的教学规则就能取得相同效果，保留这条规则就有研究价值。

实现设想可以限定为模型 API 加普通电脑 CPU。模型辅助找出相关发言，每个判断都指回对话原句，抽样由人复核。图的存储、统计和比较都可以在 CPU 上做，不依赖模型微调，也不要求处理原始课堂视频。

主数据集适合先问「不同的纠错过程能不能区分后续表现」。这项纠错研究随机分配了四种反馈条件，组内导师具体说哪一句，则取决于当时的对话。原本就比较吃力的学生，很可能自然会得到更多帮助。要进一步说明**改过的规则能让下一批学生学得更好**，还需要把原规则和新规则用到可比的学生身上，独立验证。
