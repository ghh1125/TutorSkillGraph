# TutorSkillGraph

[English](README.md) · 中文

**学生把错题改对了，AI 导师该从这次成功里学到什么？** 我们想研究，导师回顾辅导对话、准备把一种教法用在下一个学生身上时，怎样判断该保留什么经验。最终关心的是，换一道题、撤掉帮助以后，学生能否自己走出关键一步。

## 为什么一次成功的辅导也可能教给导师错误的经验？

想象两名学生列围栏长度方程时都漏掉了一项。第一名学生先解释了每一项代表什么。老师问了一句「按你的算法，哪几条边已经算进去了？」学生重新数了一遍，自己发现漏了一条边。第二场对话里，老师先点明漏的是哪条边，再问同一句话，学生也改对了。这是用来说明问题的一组假想对照。

两场辅导都可能有帮助，但它们能给老师留下的经验不一样。第一场里，追问之后，那条遗漏的关系是学生自己说出来的。第二场里，关系已经由老师提供了。如果系统每次看到学生改对，就给「追问」记一功，它可能越来越爱追问，却学错了这一招在什么条件下有用。反过来，一概给直接讲解扣分也不合理。有些学生恰恰需要听一次清楚的解释，之后才能自己用出来。

**我们想问，同样一道错题最后都改对了，学生是怎样改对的，能否告诉导师哪条经验值得复用？** 在原有水平和所遇困难相近的情况下，如果知道关键关系最早是谁提出来的、学生接下来怎样使用它，我们能否更准确地判断他在变式题上能独立做到哪一步？如果可以，导师下一次遇到相似的困难时，就有依据调整教法。

## 哪些事情已有研究已经做过？

| 已有工作 | 做到了什么，我们还能追问什么 |
| --- | --- |
| [Turning Errors into Successes，第 4.6 节](https://arxiv.org/pdf/2611.20061) | 作者已经发现，在苏格拉底式辅导组，考虑第一次就答对的题数后，纠正更多错误与变式题成绩更好相关。我们关心的是**同样成功纠错的对话之间**有什么区别。 |
| [根据学习结果选择教学动作](https://people.cs.pitt.edu/~litman/5-Chi.pdf) 与[让学生解释自己错误的研究](https://doi.org/10.1016/j.cedpsych.2024.102326) | 利用学习结果调整教学策略已有先例。实验也表明，让学生解释错误的作用与他收到的反馈有关。我们进一步问，导师修订一条经验时，该把这次成功归功于哪个环节。 |
| [REAT](https://arxiv.org/html/2609.29804v1) 与 [Eduardo](https://arxiv.org/abs/2610.06446) | REAT 会从辅导对话提炼经验，用后续轮次的评估分更新经验的权重。Eduardo 会屏蔽导师的发言，让模拟学生做近迁移题。我们想利用真人学生的纠错过程和独立作答结果，判断**究竟哪一条经验**该保留，哪一条应收窄适用范围。 |
| [StratL](https://aclanthology.org/2025.findings-acl.1348/) 与两项同名的 [HyperSkill 研究之一](https://arxiv.org/abs/2608.16114)、[之二](https://arxiv.org/abs/2611.15178) | 按预设流程图组织多轮教学、用超图表示可以组合的技能，以及在冻结模型时更新技能库，都有已有方法。这里可能有价值的贡献，是弄清一次成功辅导在什么条件下足以支持修改教法。图的价值取决于它能否帮助做出这个判断。 |

## 核心想法：让导师学会修订一条教法的适用条件

这里的教学 skill 指可以重复采用的一种教法，例如请学生解释方程中某一项的来历。一条超边可以把三个角色不同的信息放在一起：**学生原先表现出了什么理解、导师采取了什么动作、学生随后自己完成了哪一步思考。** 同一句追问可以出现在很多课堂里。关键是，提问前学生已经想到哪里，老师又已经透露了多少。

| 在什么时候 | 系统能依据什么 |
| --- | --- |
| 选择教法前 | 题目要求、学生已经写下的答案或理由，以及导师已经给过的信息。只看到一个算式时，学生为什么这样写可能还看不出来。 |
| 学生回应后 | 回到具体发言，看关键关系是学生首先提出来的、学生把老师讲过的关系用到了题上，还是只复述了一遍。对话说不清楚时，保留这种不确定性。 |
| 学生独立做题后 | 看同一名学生在相关变式题上的作答。这能帮助导师为以后的学生修订经验。第一次选择教法时，导师还不知道这项结果。 |

例如，导师起初只有一条粗略的经验：「学生方程写错了，就请他解释理由。」假如在可比的学生中，已经主动解释过思路的人和只报了答案的人，接受同样追问后的独立表现一直有区别，这条经验就值得拆开。对前者可以请他检验自己的理由，对后者可以先了解他认为每一项代表什么。如果听过直接解释的学生在新题上也能独立运用，就应该保留这种讲解的适用情形。这些是有待检验的修改方向。

## 两份数据分别回答什么？

**主数据集是 Scaffolded Error Correction。** 400 名成人被随机分到四种反馈条件，其中 99 人在苏格拉底式辅导组。仓库提供逐人结果、辅导日志和字段说明。辅导结束后，参与者立即完成五道没有反馈的后测题，其中三道是与练习对应、难度更高的变式。原协议还规定，如果导师回复六次后仍没得到正确方程，可以直接给出方程并解释。因此，看最后一个答案很容易漏掉最关键的差异。日志能告诉我们谁说了什么，学生是否真的掌握则要结合后续表现判断。[数据与字段说明](https://github.com/the-oak-lab/scaffolded-error-correction) · [原论文第 3 节](https://arxiv.org/pdf/2611.20061)

**PEA 课堂事件标注用来发现候选教法。** 这份资料把 100 段数学和信息技术课堂视频中的五个课堂阶段，与 27 类细粒度言语或非言语事件对齐。公开标注里有时间位置，类别表还包含典型前后关系和预期教学作用。我们可以从中发现值得带回辅导对话里查找的教学动作和情境。「预期作用」是对这个类别的说明，公开标注没有给出每个学生实际学会了多少。两套数据来自不同人群，能在它们之间对照的是教学假设。[PEA 论文](https://doi.org/10.1145/3767308.3838632) · [公开标注与访问说明](https://github.com/mark1001-ljj/dataset_event)

## 怎么知道这个想法值不值得继续？

最先要弄清的，是多读一层对话究竟带来了什么信息。在相同的前测和题目信息下，先看**只知道学生改对了**能判断多少，再看加入**他得到了多少帮助**后能判断多少，最后才加入**关键关系由谁提出、学生怎样使用**。用形成规则时没见过的学生做比较。如果最后一层确实有用，再让普通条件规则、带状态的有向图和超图使用同样的信息。如果一句清晰的教学规则就能取得相同效果，保留这条规则就有研究价值。

实现设想可以限定为模型 API 加普通电脑 CPU。模型辅助找出相关发言，每个判断都指回对话原句，抽样由人复核。图的存储、统计和比较都可以在 CPU 上做，不依赖模型微调，也不要求处理原始课堂视频。

现有数据适合先问「不同的纠错过程能不能区分后续表现」。研究随机分配了四种反馈条件，组内导师具体说哪一句，则取决于当时的对话。原本就比较吃力的学生，很可能自然会得到更多帮助。要进一步说明**改过的规则能让下一批学生学得更好**，还需要把原规则和新规则用到可比的学生身上，独立验证。
